# Notification Overload

An interactive, static mockup comparing normal, overloaded, and focus-mode notification experiences.

## Publish with GitHub Pages

1. Create a **public** repository on GitHub.
2. Push the files in this folder to its `main` branch.
3. In the repository, open **Settings > Pages** and set the build and deployment source to **GitHub Actions**.
4. Open the **Actions** tab and wait for `Deploy static site to GitHub Pages` to finish. GitHub will show the public site URL in the deployment details and under **Settings > Pages**.

Every push to `main` or `master` automatically publishes the latest version. The site is static and does not need a server or build step.
